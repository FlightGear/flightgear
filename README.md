## About

FlightGear is a free, open-source, GPL-licensed flight simulator available for Windows, macOS, and Linux. It has been developed in collaboration with a large group of international volunteers for over two decades.

Aside from being used by thousands of flight simulator enthusiasts, FlightGear has been used by researchers from over **40 universities and academic institutions world-wide**, as well as organizations like **NASA** and **DARPA**, and is used in several **FAA-approved flight simulators**.

## Features
- Fly anywhere on Earth (including space)
- Complex weather modelling
- Online multiplayer

## Usage

You can download brand-new releases (including release candidates) of FlightGear from GitLab [here](https://gitlab.com/flightgear/fgmeta/-/releases). Old releases can be downloaded from the FlightGear website [here](https://www.flightgear.org/download/).
